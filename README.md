# XK Eventos

Site institucional estático em HTML, CSS e JavaScript.

Os arquivos do site estão na raiz; imagens e outros recursos ficam em `assets/`. Não exige instalação de dependências ou compilação.

Para visualizar localmente: `python -m http.server 8000` e abra http://localhost:8000.

Este repositório não configura publicação automática nem domínio próprio.
